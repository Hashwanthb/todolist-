# TodoList ✅

A simple and clean Todo List application to manage your daily tasks efficiently.

![TodoList Preview](https://via.placeholder.com/800x400?text=TodoList+Preview)

## ✨ Features

- ✅ Add new tasks
- ✅ Mark tasks as complete
- ✅ Delete tasks
- ✅ Persistent storage (tasks saved even after refresh)
- ✅ Responsive design (works on mobile & desktop)
- ✅ Clean and modern UI

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript (Vanilla)
